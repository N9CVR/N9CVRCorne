<p>This is firmware for my Corne wireless keyboard with a Nice!Nano controller. To download, go to the Actions tab and select the version firmware you'd like.</p>

<p>Roadmap:</p>
<ul>
<li>Take 1: Initial functional firmware. I'm currently typing this on my Corne with Take 1 firmware.</li>
<li>Take 2: RGB LEDs support</li>
<li>Take 3: Turning off the Nice!Nano onboard LEDs.</li>
<li>Take 4: OLED support. This will likely take a while as OLED support in ZMK is flaky enough that ZMK themselves advise against using it.</li>
</ul>
